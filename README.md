# UNIX PROGRAM – Add Group and Assign Users

## Aim

To create a Linux group and assign users to the group using shell commands.

## Algorithm

1. Open Terminal on a Linux machine.
2. Create a group using the `groupadd` command.
3. Assign users to the group using the `usermod` command.
4. Close the Terminal.

## Student Task

- Assign the required users to the group.
- Use the appropriate Linux commands.
